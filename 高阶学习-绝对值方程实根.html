① 统一打法：四步，哪道题都这么走

1定形

把方程整理成「只含 x 的一边 = 只含 a 的一边」。 能分离参数就分离；分不开（右边是 ax 这种）就把它当成一条随 a 转动的直线。

2画形

画出 y = f(x)。有绝对值就翻折。 只需三样东西：零点在哪、极值点在哪、两端往哪走。

3扫线

让 y = a（或那条直线）从下往上扫， 记下交点个数在哪几个高度发生跳变。这几个高度就是分类的临界值。

4验端点

把每个临界的 a 单独代回去数一遍。 分数基本都丢在这一步——答案常常是「一个孤立点 ∪ 一个区间」。

为什么非要画图？因为题目问的是「根的个数」，不是「根是多少」。 个数 = 交点个数，而交点个数一眼就能数出来；硬解方程反而要分一堆情况，还容易漏。

② 选路：看到什么样子，走哪条

方程长这样走哪条路第一步做什么
|一次式| = 常数直接定号先问右边能不能为负、能不能为零
|x−u| + |x−v| = a距离之和求两点间距 = 谷底高度，谷底是一整段
|x−u| − |x−v| = a距离之差两端是水平射线，先确认它永远给不出两解
|二次式| = a翻折 + 扫水平线配方求零点和峰高
只含 x² 和 |x|换元 t = |x| ≥ 0先写死 t ≥ 0，再想 t 的根怎么翻译回 x
右边含 x（如 ax、ax+1）定点 + 转动直线找直线恒过哪个点，再看斜率转到哪

③ 换元法的关键：t 的根数 ≠ x 的根数

令 t = |x|，则每一个 t > 0 对应 2 个 x（x = ±t）， t = 0 只对应 1 个 x，t < 0 要舍去。
所以要让原方程恰有 2 个不同实根，t 的方程只有两种合法情形：
　(i) 恰有一个正根（另一根为负或不存在）；
　(ii) 有一个正的二重根。
第 (ii) 种最容易漏——判别式等于零的那个孤立的 a 值。

以 x² − 2|x| + a = 0 为例。换元后是 t² − 2t = −a， 于是又变成「一条抛物线 + 一条水平线」，只不过左半边 t < 0 整片作废：

④ 必须背熟：|f(x)| = a 的根数表（以 f(x) = x² − 2x 为例）

y = |x² − 2x|：把抛物线在 x 轴下方的部分翻折上去， 得到两个零点 x = 0, 2，中间鼓起一个峰，峰高 = 原顶点纵坐标的绝对值 = 1。 下面这张图把五种情况画在了一起——水平线每升高一点，交点个数就跟着变：

a 的范围水平线位置交点（实根）个数
a < 0在 x 轴下方（图中没画）0 个
a = 0绿线：正好是 x 轴2 个（两个零点）
0 < a < 1橙线：穿过峰的腰部4 个
a = 1红线：正好擦过峰顶3 个
a > 1紫线：高过峰顶2 个
所以 |x² − 2x| = a 恰有两个不同实根 ⟺ a = 0 或 a > 1。
对着图看就明白为什么答案不是一个区间：两个「2 个根」的情形，一个在最底下（贴着 x 轴）， 一个在最上面（高过峰顶），中间被 4 个根和 3 个根隔开了。a = 0 这一支，十个人里有八个会漏。

⑤ 通用的峰高怎么算

设 f(x) = x² + px + q 有两个不同实根，则 y = |f(x)| 的峰高就是 |f(−p/2)|，即原抛物线顶点纵坐标的绝对值。
例：|x² − 4| 顶点 (0, −4)，峰高 4 ⟹ 两根 ⟺ a = 0 或 a > 4；
　　|x² − 2x − 3| 顶点 (1, −4)，峰高 4 ⟹ 两根 ⟺ a = 0 或 a > 4。
若 f 本身没有实根（判别式 < 0），则 |f(x)| = f(x) 全程为正，图像不翻折，根数表完全不同，要重新讨论。

⑥ 一字之差，图形天壤之别：距离之「和」与距离之「差」

左图底部是一段水平的谷底，所以 a 等于最小值时是无穷多解， 比最小值大才是两解；
右图两端都是水平射线，中间严格单调，所以要么无穷多解、要么恰一解、要么无解， 永远不可能恰好两解。
看一眼图就能定性，比硬分段快得多。

⑦ 写完先别交：照着这五条过一遍

这五条不是「知识点」，是动作——每条都要真去做一遍，不是读一眼。

□ 右边能不能是负的？ |g(x)| = h(a) 先要求 h(a) ≥ 0； 等于 0 时往往是重根，只算一个。
□ 分段解出的根，回代了吗？ 在 x ≥ 2 这一段解出 x = 1， 必须舍掉。解一段，验一段。
□ 换元后翻译回 x 了吗？ t > 0 给 2 个 x，t = 0 给 1 个， t < 0 舍。t 的两个正根是 4 个 x，不是 2 个。
□ 临界的 a 逐个代回去数了吗？ 峰高、判别式为零、两根重合——这几个值一个一个代， 别想当然。a = 1 擦顶是 3 个根，写 a ≥ 1 就错了。
□ 答案只写了一个区间？ 回头想想有没有漏掉孤立点。 这类题的标准答案形状常常是「a = 0 或 a > 1」。
